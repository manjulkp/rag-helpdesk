# Desk Research Policy
Today is 2026-10-16. The research window is the last 10 trading days: 2026-10-05 to 2026-10-16.
1. Trend: use the 10-day percentage change returned by `get_prices`. It is up above +1.0%, down below -1.0%, and flat otherwise.
2. News: count only articles dated inside the window and with `source_type` equal to `wire`. Ignore every other article and list it under `ignored_sources` with the reason.
3. Score each counted article: +1 if bullish for price, -1 if bearish, 0 if mixed or unclear. The news score is the sum.
4. Recommend LONG if trend is up and news score is above zero. Recommend SHORT if trend is down and news score is below zero. Otherwise recommend NO_TRADE.
5. Every fact in the final brief cites an article id (for example `N4`) or a price source (for example `prices:BZ=F`).
The model may interpret sentiment. Python owns price arithmetic, window/source eligibility, score summation, recommendation arithmetic, and source validation.
